# Bongo Ocean Dashboard

The Bongo Ocean Dashboard is the secure staff management portal behind Bongo Ocean, a global B2B & B2C vendor marketplace platform in the spirit of Alibaba.

Managers, administrators, and super administrators can manage products, categories, brands, suppliers, stock/inventory, orders, customers, staff accounts, product reviews, and real-time customer or visitor conversations from one place.

The dashboard also provides period-based order and revenue analytics, delivery performance, best-selling product insights, a full activity log audit trail, global navigation search, and role-based account access.
